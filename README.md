# Proyecto BLURE - Laboratorio SIEM y Defensa Activa

Repositorio que contiene los scripts de prueba de concepto, reglas de auditoría y algoritmos de correlación desarrollados para el trabajo final del Máster en Ciberseguridad.

## Estructura del proyecto
- `scripts/honeytoken/`: Monitorización del archivo trampa mediante `auditd`.
- `scripts/tarpit/`: Configuración de reglas `iptables` y respuesta TARPIT.
- `scripts/impossible_travel/`: Algoritmo Haversine en Python para alertas de geolocalización.
